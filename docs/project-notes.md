# Oxypro Project Library (app notes)

Developed by Mark Lontoc | Dubai, United Arab Emirates | © 2026 MLWorks. All rights reserved. Current version 1.10.2 (27 Oct 2026), shown in the footer. About (header button and footer link, 1.10.2, user request) opens what it does, how to use it, your data, related apps, What's new (version history) and credits. The PROJECT LIBRARY title in the header goes back to the library list from any page (1.10.1, user request); the MSRA Log asks first when it has unsaved changes.

**What it does:** one shared list of Oxypro projects with search and filters (emirate, status, sector, sort by project no., name, emirate or year), a detail panel per project with up to 5 library photos, and a presentation builder: select one or more projects and get a top sheet, the Oxypro Project Presentation Sheet for each project (A4 landscape, layout of the 2.0 template: hero photo, four-photo gallery, project name, scope, six details with icons) and a project summary as the last page, as a PDF (one page each) or a PowerPoint (one slide each). View / Present runs the same pages full screen before saving. PQP details and file (project detail panel) opens the PQP Maker with the project's PQP already created, or saves it as a .pqp file. Create MSRA Log (beside it) opens the project's Method Statement Log page. Projects are added with Add project or Import from Excel; Export to Excel gives the whole list in the Projects Master List layout. A View menu in the header switches the background between Light (white), Dark and Auto (follows the Claude app); the choice is remembered per browser.

**MSRA Log (1.10.0, user request 27 Oct 2026: "Create MSRA Log" next to PQP details and file, a page to create, edit, view, Save as and Print each project's Method Statement Log, with the attached "Method Statement Log - The Borough R0.xlsx" as the template; font Open Sans by Steve Matteson for the page, the PDF and the Excel at the user's request):**
- Button: "Create MSRA Log", or "Open MSRA Log" once the project has one. Opens a full page (Library back button) with tabs Summary, MEC, PLU, ELE, ELV, FF, LPG, MEP and MSL Ref.
- Start (user's choice 27 Oct): Standard list = the template's 72 method statements from item no. 1 (48 installation + 24 T&C: MEC 16+6, PLU 12+4, ELE 9+6, ELV 3+3, FF 4+3, LPG 1+1, MEP 3+1), recommended; Standard list and the project's MSL; or Empty log. Method statements can be added (per section), removed (asks first), moved up or down; titles typed in capitals become Title Case.
- Project block: PROJECT, CLIENT, CONSULTANT, MEP CONSULTANT, CONTRACTOR, MEP CONTRACTOR, filled from the library (upper case, no M/s; MEP CONTRACTOR = OXYPRO ELECTROMECHANICAL WORK LLC), labels and values editable, up to 6 rows, "Refill from the library"; a log revision (default 00) goes into file names.
- Columns as the template: No., Unifier Ref. Number, Method Statement Title, Reference No., Rev. (0), Discipline, Planned Submission Date, Submitted Date, Return Date, Review Period (return − submitted), Status, Final Status (A, B, C, D, E, UR, n/a in the template colours), Remark. Planned dates are typed in the log (user's choice); planned dates past without a submitted date show red, due within 7 days amber. Counter strip and the Summary (Overall, Installation, T&C) follow the template's formulas.
- View shows the log like the printed sheet (white paper in every theme, title, block, logo and legends stay in view when scrolling sideways; No., Unifier and Title frozen on wide screens). Edit makes the cells inputs. Save to library is for editors (Ctrl+S too); others can edit and download but not save. Leaving with unsaved changes asks. If another editor saves meanwhile, a notice offers their version.
- Upload MSL (the planner's Material Submittal Log, .xlsx): reads every visible sheet with a "Description" column; discipline from the sheet name (HVAC/PL/EL/ELV/FF/LPG/MEP) or from section rows (ELECTRICAL, PLUMBING, HVAC …); SN, planned submission date (a "Planned" column under "Submittals", or "PLANNED SUBMISSION DATE") and lead type when present. Keys <DISC>-<SN>; items without an SN get the next free number. Each material is matched to the standard's own Borough materials (word similarity, synonyms, discipline), which links it to the standard method statements that material belonged to; the review dialog shows linked and not-covered materials and can remove the method statements no material needs. MSL Ref lists the materials with linked method statements; Link (tick method statements) or Add MOS (installation and optional T&C) for each; "Fill empty planned dates" = first related material date + 14 days (installation) or last + 14 (T&C), Sunday → Monday, typed dates kept (lags editable). Tested 27 Oct with the laptop's The Borough MSL (97 materials, all matched to the template's own links) and CBD2 tracker R01 (101 materials, 86 linked, 15 not covered: BMS, UPS, lighting fixtures by client, aircraft warning lights, disabled toilet alarm, chiller, BTU meters, sanitary ware, car park system and a few more).
- Save as: Excel workbook = Summary (logo, print area A1:M15, columns C and E hidden as in the template), the seven logs (template widths, 20/40/30 pt rows, taller only when a title needs a third line in Open Sans, LEGENDS, counter strip with COUNTIF formulas, headers, banners, review formulas, status and planned-date conditional formats, status drop-downs, freeze at row 13, filter, print titles 11:12, A4 landscape fit to width, logo at H2; column P "Related Material Submittal(s)" hidden when an MSL is loaded), hidden MSL Ref (with linked-MOS counts) and hidden MS Master List (live formulas, Progress, links to the rows). PDF = Summary (all three tables) and each discipline log with items, A4 landscape, header rows repeated, page numbers. Print makes the same PDF named "… - Print.pdf" (claude.ai cannot open the print dialog). File names "<project code or no.> - <name> - Method Statement Log - Rev 00.xlsx/.pdf". Libraries: ExcelJS 4.4.0 and jsPDF-AutoTable 3.8.4 from cdnjs, loaded on first use.

**View / Present (1.6.0):** button beside Download PDF on the presentation page. Opens a dark full-screen viewer (falls back to filling the window when the browser or frame refuses full screen) with the pages exactly as the PDF prints them: top sheet if included, the project sheets, the summary pages if included; empty frames and placeholder text left out. Moves with arrow keys, Space, Page Up/Down, Home/End, mouse click, wheel, the side arrows, or swipe and tap on touch screens. The top bar (page x / n and the page name, All pages, Full screen, Close) and the progress line hide after about 3 seconds without mouse movement in full screen. All pages (G) shows every page as a thumbnail to jump to. After the last page an end card offers Download PDF, Download PowerPoint, Start again and Back to editing (downloads leave full screen first so the save prompt shows). Esc or Close goes back to editing on the page last shown. It is a snapshot taken when opened; edits made after need a reopen.
